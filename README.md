# Лабораторна робота №2: Дослідження продуктивності та оптимізації коду

## Опис проекту
У даній лабораторній роботі досліджено вплив прапорців оптимізації компілятора GCC (`-O0` та `-O3 -march=native`) на швидкість виконання, використання процесних ресурсів та енергоефективність C++ програми.

## Налаштування середовища
- **ОС:** WSL2 (Ubuntu 24.04 / 22.04 LTS) на Windows 11
- **Компілятор:** GCC 15.2.0
- **Обсяг даних:** 5,000,000 елементів типу `double`
- **Інструменти вимірювання:** `/usr/bin/time --verbose`

## Аналіз асемблерного коду (`asm_O3.s`)
При аналізі згенерованого асемблерного коду `asm_O3.s` було підтверджено автоматичну векторизацію (SIMD):
1. **AVX Інструкції:** Застосовуються векторні команди з префіксом `v` та суфіксом `pd` (Packed Double), такі як `vmovupd`.
2. **Векторні регістри:** Використовуються 256-бітні регістри `ymm0` (наприклад, `vbroadcastsd .LC4(%rip), %ymm0`).
3. **Ефект:** Процесор обробляє по 4 елементи `double` паралельно за один машинний такт, що забезпечило скорочення часу обчислень з 5.34 с до 0.27 с.

## Оцінка енергоефективності
Згідно з формулою енерговитрат:
$$E = P \times t$$
де $E$ — спожита енергія (Дж), $P$ — потужність (Вт), $t$ — час виконання (с).

Незважаючи на те, що використання AVX-векторних блоків може короткочасно збільшувати пікову потужність процесора ($P$), скорочення часу виконання ($t$) у ~20 разів зменшує загальне споживання енергії ($E$) на обробку масиву у відповідну кількість разів.

## Висновок
Застосування оптимізації `-O3 -march=native` забезпечило **пришвидшення виконання програми майже у 20 разів** та суттєве підвищення енергоефективності за рахунок апаратної векторизації (AVX/SIMD) та розгортання циклів компілятором GCC.
